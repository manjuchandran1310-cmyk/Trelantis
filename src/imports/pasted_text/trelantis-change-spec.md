# Trelantis Website — Change Spec (Refined)

All changes aligned with latest pitch deck and script. No changes to core colours (navy, gold, white), typography, or layout structure. All copy has been stripped of "not X, but Y" constructions and vague/AI-sounding language.

## 1. HERO SECTION

| Element | Current | Change to |
|---------|---------|-----------|
| Eyebrow | `FOR PARTNERS WHO READ BEFORE THEY SIGN` | `BEFORE YOU COMMIT` |
| Headline | `The reasoning behind every commitment.` | **Keep as is** |
| Subtext | `Trelantis reads your engagement pack and tells you what will bite you — before you commit. Not a summary. Not a search. A point of view on where your exposure lies.` | See below |
| CTAs | `Request Early Access` / `See how it works →` | **Keep as is** |
| Product screenshot | Dashboard with findings | **Keep as is** |

**New subtext:**
> Trelantis reads your engagement pack and identifies the assumptions most likely to cost the firm money — before you sign. A structured view of where the commercial risk sits and what to do about it.

**Why:** Removes the informal "what will bite you" and the "Not a X. Not a Y." pattern. Introduces "assumptions" and "commercial risk" — the pitch deck's core language.

## 7. PRICING SECTION

**This section has a fundamental mismatch with the pitch deck and needs a decision from the team before changes are made.**

### Current website pricing:
- Per Review: £500/review
- Volume Bundle: £350/review (after 20 reviews)
- Value Based: 0.2% of fee value

### Pitch deck pricing:
- Single model: 0.15% of engagement value
- Floor: £250 per matter
- Cap: £5,000 per matter

### What needs to happen:

**If the pitch deck model is correct**, replace the three-tier layout with a single pricing presentation:

| Element | Value |
|---------|-------|
| Headline | `Access structured for how firms actually work.` (keep) |
| Sub | `No seat licences. No procurement approval required. Our fee scales with what we protect.` |
| Rate | `0.15%` of engagement value |
| Floor | `£250` per matter |
| Cap | `£5,000` per matter |
| Example | `e.g. £1M matter → £1,500` |
| Features | Full consideration analysis · Commercial and structural findings · Source extract tracing · PDF and Word export · NDA-protected environment · Slack and email delivery |
| CTA | `Request Access` |
| Trust strip | `SOC 2 TYPE II · DATA NEVER USED FOR MODEL TRAINING · UK AND EU DATA RESIDENCY` (keep) |

**If the website pricing is correct**, update the pitch deck to match. Either way, the Value Based tier currently says 0.2% — the deck says 0.15%. These cannot show different numbers to the same stakeholders.

**UX note on "MOST POPULAR" tag:** If three tiers are kept, replace this tag — partners don't care what's popular. Use `RECOMMENDED FOR FIXED-FEE PRACTICES` or remove the tag entirely.
